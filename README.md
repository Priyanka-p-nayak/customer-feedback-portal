# Customer Feedback Portal

## Project Overview
The Customer Feedback Portal is a project designed to help customers submit feedback and allow staff members to view and manage it.

## Objectives
- Make feedback submission easy for customers.
- Help staff view customer feedback.
- Organize project tasks using Agile project management.

## Project Management
This project is managed using GitHub Projects with four statuses:
- Backlog
- Sprint
- In Progress
- Done

## User Stories
1. Submit Customer Feedback
2. Validate Feedback Form
3. Show Confirmation Message
4. Staff Login
5. View Customer Feedback
6. Search and Update Feedback

## Documentation
The Software Requirements Specification (SRS) describes the purpose, scope, users, and functional and non-functional requirements of the portal.
